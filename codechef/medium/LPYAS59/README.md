# LPYAS59

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Write a program to check whether a number given as user input is positive, negative, or zero.

### Sample 1:
Input
Output

```
20
```

```
Positive
```

### Sample 2:
Input
Output

```
0
```

```
Zero
```

### Sample 3:
Input
Output

```
-95
```

```
Negative
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-05T15:10:08.100Z  

```py
# cook your dish here
n=int(input())
if n>0:
    print("positive")
elif n==0:
    print("zero")
else:
    print("negative")
```
