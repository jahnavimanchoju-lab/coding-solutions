## Problem

### Coding Problem

Listen

You are given the age of a person as the variable  **`age`**.
Will this person be able to vote?

### Task

Output `True` or `False` assuming that the voting age is $18$ i.e., a person's age has to be greater than or equal to $18$ to vote.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-07T16:16:13.718Z  

```py
age = 20
# Update your code below this line
if age>18:
    print(True)
else:
    print(False)
```
